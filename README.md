# Rentora – Backend

Backend API for Rentora, an equipment rental platform.

### Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT Authentication

### Features

- User Authentication & Role Management
- Equipment Management
- Equipment Search & Filtering
- Equipment Booking & Rentals
- Favorites Management
- Payment Management
- Admin Dashboard & Analytics

### Installation

```bash
git clone <repository-url>
cd rentora-server
npm install
```

### Run Locally

```bash
npm run dev
```
